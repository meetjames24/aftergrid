GoBag: scans and copies of what you'd need if you lost everything.
This folder lives on Aftergrid's encrypted part of the stick.

IDs/        passport, ID card, driver's licence (both sides)
Medical/    prescriptions, vaccination records, allergy list, recent test results
Insurance/  policies, property deeds, vehicle papers
Contacts/   a list of phone numbers you know only from your phone

Print an emergency card for each person: Field Mode -> Go-Bag.
